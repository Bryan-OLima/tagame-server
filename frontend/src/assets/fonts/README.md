# Fontes do TAGAME

As fontes são hospedadas localmente para que o painel não dependa de CDN em tempo de execução.

| Família | Arquivo | Peso variável | Licença |
|---|---|---:|---|
| Oxanium | `oxanium/oxanium-latin.woff2` | 200–800 | SIL Open Font License 1.1 (`oxanium/OFL.txt`) |
| Inter | `inter/inter-latin.woff2` | 100–900 | SIL Open Font License 1.1 (`inter/OFL.txt`) |
| JetBrains Mono | `jetbrains-mono/jetbrains-mono-latin.woff2` | 100–800 | SIL Open Font License 1.1 (`jetbrains-mono/OFL.txt`) |

Os arquivos são subconjuntos latinos oficiais fornecidos pelo Google Fonts. São registrados em `src/styles.css` com `font-display: swap`.
